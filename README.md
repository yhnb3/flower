# 花 Planner

Single-page folder-tab todo app built with React, Vite, and StyleSeed.

## Design Method

- StyleSeed lock: `STYLESEED.md`
- Effective rules: `.styleseed/effective-rules.md`
- Rule set: `consumer-service x product-ui x productivity x list x calm-consumer x none`

## Commands

```bash
npm install
npm run dev -- --port 5173
npm run build
```

Open `http://127.0.0.1:5173/` while the dev server is running.
